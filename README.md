# Final-project-of-HTML-CSS-JS

🎮 Riddle Game Portal

Final Project – HTML, CSS & JavaScript

📌 Project Overview

The Riddle Game Portal is an interactive web application where users can play riddles, view results, and check their ranking on the leaderboard.
The project focuses on creating an engaging user experience using HTML, CSS, and JavaScript.

This project demonstrates front-end development skills including responsive layout design, interactive game logic, and organized project structure.

🌐 Live Website

🎯 Objectives

Build an interactive riddle-based web application

Design multiple responsive webpages

Implement game logic using JavaScript

Create a simple and engaging user interface
